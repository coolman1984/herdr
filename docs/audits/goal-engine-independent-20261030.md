## اختبارات إضافية واجبة
- تشغيل مشرفين وحارسين معًا؛ موت الحارس والمشرف معًا؛ إعادة تشغيل الجهاز؛ إعادة استخدام رقم عملية قديم.
- قتل قبل وبعد كل من: حفظ النية، تشغيل الوكيل، تسجيل النافذة، الإرسال، الإقرار، كتابة النتيجة، الدمج، انتهاء الاختبار، حفظ الحالة.
- فشل الإيقاف؛ وكيل خرج وبقيت الصدفة؛ رسائل مكررة ومتأخرة وخارج الترتيب؛ تغير شاشة بين القرار والإرسال.
- إلغاء/تحديث/إعادة مهمة أثناء فحصها؛ تراجع أثناء دمج؛ نتيجة مراجع قديم؛ اختلاف الكود بعد المراجعة.
- حذف أو تعطل ملفات الحالة؛ سطر مقطوع وسط السجل وليس آخره فقط؛ قرص ممتلئ؛ رفض صلاحية؛ برنامج حماية يقفل الملف.
- ملفات عربية ومسارات طويلة ومسافات وشرطة مائلة وروابط رمزية ووصلات ويندوز؛ تغيّر ساعة الجهاز والسكون والاستيقاظ.
- نماذج غير متاحة، انتهاء اشتراك، كل الحسابات محدودة، خطأ مصادقة، مخرجات ضخمة، تعليق Git أو اعتماد غير موجود.
- حقن تعليمات داخل مستند أو صفحة ويب أو نتيجة وكيل؛ نتيجة pass مزورة؛ تسريب ملفات حساسة داخل git add -A.
- لا تعتبر الاختبار الذي يستبدل كل الوكلاء ببرنامج واحد دليل تنوع أو استقلال مراجعة.

- SQLite: https://github.com/sqlite/sqlite — سجل وتشغيل محلي بمعاملات؛ صمّم كاتبًا منسقًا، معاملات قصيرة، نسخًا احتياطية صحيحة، ولا تستخدم ملف قاعدة مشتركًا على الشبكة كبديل لخادم متعدد الأجهزة.
- DuckDB: https://github.com/duckdb/duckdb — محرك تحليلات داخل العملية؛ مرشح للتجميعات الضخمة مع ملفات عمودية، بعد قياس حقيقي مقابل SQLite.
- Arrow: https://github.com/apache/arrow — دفعات وأنواع وملفات عمودية وتبادل بيانات دون تحويلات نصية متكررة.

- Playwright: https://github.com/microsoft/playwright — تحقق فعلي للمتصفح، عزل وتتبع واختبارات واجهة.

## ما أُعد فعليًا في حزمة المراجعة
- هذا التقرير وبرومبت تنفيذ مرتب ومحدد القبول.
- ستة اختبارات رجوع مكتوبة من السلوك المطلوب؛ لم تُشغّل هنا.
- خمس مهارات مرشحة من مصادرها، مع ملفاتها التابعة وترخيصها وتثبيت المصدر؛ غير مفعلة حتى تقييمها.
- سجل مصادر وسياسة انتقاء ودمج مهارات. لا يوجد ادعاء بأن جهاز المستخدم أو فرع كلود الجاري تم إصلاحه.
