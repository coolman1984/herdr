# Herdr Deck: new features ranked by value / cost

**Build the first 10.** The strongest additions prevent bad starts, conflicting edits, repeated work and false “done” reports. Keep the existing parity work first. Research checked headlessly on 2026-10-24.

All rows are **proposed Herdr adaptations**, not claims that another product implements the exact safeguard described. The source column names the verified inspiration. Benefits and ranking are judgments for this owner; costs are estimates, not measured delivery times. S = small addition; M = several connected changes; L = substantial new machinery. Endpoint means **additional backend support beyond the three task specs**, including changes to existing endpoints; suggested capabilities are not existing API promises.

## Five anti-features to avoid

| Avoid | Reason for THIS owner | Official comparison / local rule |
|---|---|---|
| 1. A bundled IDE with editors, spreadsheets, diagram canvases and an extension runtime | Large scope and dependency burden conflict with the light single-exe target. Its actual RAM cost on this PC is **not verified**. | [Crystal’s replacement advertises Monaco, spreadsheets, Excalidraw and Electron](https://github.com/stravu/crystal#nimbalyst-features); Deck app spec §4. |
| 2. Browser-driven research and automatic application previews | Repeats the browser/RAM pain; research must remain headless. Do not embed a second browsing workflow into Deck. | [Claude Desktop offers browser and computer-use surfaces](https://code.claude.com/docs/en/desktop); CLAUDE.md §0, AGENTS.md §7, LESSONS #56. |
| 3. “Unblock all,” approval bots, trust-all or credential forms | The owner alone answers blocked agents and enters sign-in secrets. Keep existing owner-click key controls; never let the lead impersonate that decision. | [Warp exposes configurable autonomy and permissions](https://docs.warp.dev/agents/capabilities/agent-profiles-permissions/); CLAUDE.md §2.1–3. These controls are not permission to change this owner’s settings. |
| 4. Automatic commit/merge/rebase/reset or delete-on-idle | A guessed idle state is not proof of completion, clean work or ownership. No git mutations belong in the present Deck API. | [Claude Desktop documents automatic fixes and merge-when-ready](https://code.claude.com/docs/en/desktop#monitor-pull-request-status); [Vibe Kanban documents permanent workspace deletion](https://www.vibekanban.com/docs/workspaces/managing-workspaces#deleting-workspaces); CLAUDE.md §2.5; app/API.md. |
| 5. Permanent full scrollback, never-ending live panes and unlimited retention | Closing finished panes is mandatory; storing every screen forever also spends disk. Retain bounded task evidence, not secrets or complete terminal archives. | [Zellij warns that saving more scrollback increases resource/cache use](https://zellij.dev/documentation/session-resurrection.html); CLAUDE.md §0. |
