## Additional implementation findings, requiring fixes and focused regression evidence

1. **Cancellation and shared Git state:** `cancelJobs` removes a cancelled job immediately without waiting for its completion. A replacement main-branch operation can overlap cleanup still running. `runReverts` uses workspace revert operations that are not governed by the cancelling context. Keep cancelled jobs counted and owned until joined, serialize all shared-repository mutations, and reconcile process/job receipts after a supervisor kill. Rejecting an old result does not undo its side effects.
2. **Authentication material in the inbox:** `Enqueue` serializes the bearer `Command.Token` into `inbox.jsonl`, created with mode `0644`. Clearing the decoded field does not remove the original credential from disk. Use a narrowly scoped authenticated command transport or message-bound authentication with replay protection, restrictive OS ACLs, and redacted persistent records. Same-OS-user agents are not isolated merely by role environment variables or a worktree; document and enforce the actual boundary.
3. **Reviewer independence:** a different model vendor is useful but not sufficient. Protect acceptance criteria, trusted tests, ledger, control endpoints and reviewed commit from writers/reviewers. Review an immutable commit and test from a protected integration context; bind approvals and artifacts to that exact commit and policy version.
4. **Office cleanup and ownership:** Python timeout kills the PowerShell subprocess; it does not guarantee the COM server exits or its `finally` runs. `New-Object -ComObject` plus `Quit()` also does not prove an exclusive Office instance, especially across application types. Establish owned process/session identity, apartment/thread policy and a recovery protocol. Never close a user's existing documents. Test a hanging dialog, killed worker, reused instance and long-running Office operation on real Windows.
5. **Company output policy:** worker always materializes extracted content in a temporary JSON file; Python cleanup occurs only on success. This needs an explicit authorized output location/permissions/retention policy, cleanup on error, and bounded transport. Any SQLite database, logs, screenshots, dashboard export and agent context derived from protected data must follow the same company policy; do not upload company content for research. Do not assume that successful COM read authorizes plaintext export.
6. **PowerShell execution policy:** `-ExecutionPolicy Bypass` is unconditional. Respect the actual device's allowed execution mode and use a supported signed/approved path; blocked policy is a capability fact, not an instruction to weaken device restrictions.
7. **Bounded memory:** CSV reads the whole source into memory. COM copies entire `UsedRange.Value2` before checking `MaxCells`, then stores every record and creates a whole-document JSON string. `totals` stores every contributing source pointer in a Python list; CSV export builds the whole download in `StringIO`. Make these pipelines bounded end-to-end, with measured batch budgets, paging/backpressure and spill-to-local approved storage. The 300k-row native XLSX benchmark does not establish the COM/CSV/dashboard envelope.
8. **Adversarial documents:** OOXML merged ranges are expanded into individual cells, shared strings are fully resident, and Word/PPT XML is loaded whole. ZIP-ratio checks do not bound post-parse expansion. Limit rows, columns, merge area, shared-string bytes, XML depth/text and extraction work before allocation; test sparse huge ranges, malformed ZIP/XML, many tiny entries and oversized text without exhausting the host.
9. **Import identity and concurrency:** identity is raw SHA alone; it omits access-policy profile, parser/schema version and extraction configuration. Completed imports can be incorrectly reused after a policy/parser change. The source can change between hash and extraction. Multiple importers can share/rewind one checkpoint; migrations read schema version before acquiring their write transaction. Add validated snapshot identity, monotonic checkpoints, an import owner/lease, transactional migration recheck and a local single-writer architecture. Prove recovery with concurrent import, source mutation, schema upgrade, disk full and interrupted backup.
10. **Semantic accounting:** numeric Excel cells discard currency formatting in normalization. Formula records are labelled Excel-computed without proving recalculation/cache freshness. Word/PPT table records do not carry a tabular row/column identity usable by the report mapper; Word paragraphs can duplicate table content. Preserve units, currency, formula provenance/freshness, table identity and duplicate policy. Do not silently aggregate different currencies, ratios, identifiers, subtotals and totals.
11. **Dashboard scale and exports:** page handlers do not explicitly close their SQLite connections. Dashboard totals and quality checks rescan large data and gather unbounded source lists. CSV download is unbounded and passes text beginning with spreadsheet formula characters unchanged; specify safe human-facing export and a distinct lossless machine format. Use bounded queries, pagination, explain-plan evidence and cancelled-request cleanup. Non-loopback service needs an explicit protected deployment mode.
12. **Live capability enforcement:** initial discovery reads cgroup limits, but subsequent RAM admission uses host probes. The report is loaded at run start without a freshness contract, and derived `BatchRows` is not wired into docpipe. A tool existing or a COM ProgID being registered is not proof it works. Refresh relevant facts after resume/config change; enforce effective container/OS resource budgets in every launch path and pass batch limits to workers.
13. **PowerShell-only operation remains missing:** product orchestrates document work through Python and only uses PowerShell for COM extraction; the document skill requires Python. There is no demonstrated end-to-end path for a Windows machine with PowerShell and Office but no usable Python/package installation. Choose a supported installed backend before planning. Stdlib Python does not include `win32com`; use the PowerShell bridge when that package is absent. Do not promise to recreate arbitrary DRM, PDF/OCR or Office engines from scratch.
14. **Quota integration is incomplete:** Claude default config directory maps to `main`; reconcile that with configured account aliases and canonical subscription identities. Validate state, range, timestamp, reset and schema; a passed reset timestamp is not fresh measured zero. Sampling currently does synchronous provider reads under a shared lock; slow commands can block the watchdog. Cache asynchronously with deadlines. Verify real installed CLI formats, including any Antigravity/Cline providers that expose data; record unsupported windows explicitly rather than inventing a five-hour or weekly percentage. If all eligible accounts are unavailable, durably wait and resume at the next justified retry/reset without cycling aliases to evade limits.
15. **Skill selection is opt-in by environment variable:** absent `HERDR_SKILLS_CATALOG` means no catalog is loaded. Mandatory environment policy can be omitted by tag matching and a three-skill cap. Paths are not checked against allowed real paths and there is no pinned expected full digest; a truncated computed hash records current content but does not verify integrity. Add automatic trusted catalog discovery, mandatory policy injection outside optional ranking, path/symlink containment, pinned full hashes, token budgets and explicit selection evidence.
16. **Research and skill effectiveness are not runtime gates:** candidate imports remain unevaluated; a passing tool suite does not show a skill improves an actual agent. Preserve mandatory company policy as policy, separately from learned-skill approval. Require a research/decision record before plan acceptance, bounded research fallback when offline, and risk-triggered research after unfamiliar/repeated failures. Evaluate candidates on representative held-out tasks with/without the skill: correctness, time, tokens, failure recovery and policy adherence. Keep licensing and pinned upstream provenance; do not execute arbitrary discovered code.

## Product scope still not delivered

The document pipeline and a small dashboard demonstrate a useful vertical slice. They do not establish complete enterprise reporting, complex web applications, award-level visual design, arbitrary PDF extraction/OCR, all Word/PowerPoint structures, or a database suitable for any scale. Maintain capability contracts per file type and device. Build representative end-to-end acceptance goals: protected Excel/Word/PPT/PDF ingestion, reconciled multi-file reporting, a large-data executive dashboard, and an accessible polished web application. Establish functional, visual, interaction and performance baselines; no claim of an award or universal support follows from a few browser tests.
